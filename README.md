# Inventario-Forestal-Nacional

Sebastian David Castro Alvares - Jimmy Alejandro Vela Aparicio

Sistema de software desarrollado en Python bajo una arquitectura de tres capas para brindar soporte a la ejecución del Inventario Forestal Nacional del IDEAM. El sistema permite gestionar y consultar información detallada de los conglomerados forestales, las brigadas de levantamiento, los conteos de árboles y el muestreo de especies vegetales, asegurando la persistencia de los datos mediante archivos de texto plano con interacción por consola.
